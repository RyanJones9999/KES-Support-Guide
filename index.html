📊 TCE - KES Excel Import & Export Tool

This Python application provides a graphical interface for importing, updating, and exporting project data from Excel files. It is designed to streamline the management of project timelines and audit trails for the KES (Key Execution Schedule) system.

🧰 Features

  • Import Functionality:

    • Load and compare Excel files from a selected folder against a master tracker.
    • Automatically update the master file with new or changed data.
    • Maintain an audit trail of all changes with timestamps and user information.
    • Create backups before any modifications.

  • Export Functionality:

    • Export project data grouped by:
      • Project
      • Action Owner
      • Installation Contractor
    • Exported files are saved in timestamped folders for easy tracking.

🚀 How to Use

  • Run the Script

    • This script is intended to be packaged into an .exe and run that way.

  • Importing Data

    • Select the Master Excel File.
    • Select the Folder containing project Excel files.
    • Click Start Import to process and update the master file

  • Exporting Data

    • Export by Action Owner
    • Export by Project
    • Export by Installation Contractor

  • The tool will generate seperate excel files for each group in a timestamped folder

📁 File Structure

  • Master File: Must contain sheets:

    • KES DATES – main project data
    • Audit Trail – logs of changes

  • Import Files: Excel files with matching structure to the master file

🛡️ Safety & Logging

  • All changes are logged in the Audit Trail sheet.
  • Backups are created before any write operations.
  • Errors during processing are logged and shown in the console and GUI.

📌 Notes

  • Ensure all Excel files are closed before running the tool.
  • The tool assumes consistent column names across all files.
  • Designed for internal use in project tracking environments.
